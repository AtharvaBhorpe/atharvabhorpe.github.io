## Steps

### 1. Install ROS 2 Jazzy

Follow the [official ROS 2 Jazzy installation guide](https://docs.ros.org/en/jazzy/Installation.html) for your operating system.

### 2. Install Isaac Sim

Use the project's [Pixi-based Isaac Lab setup guide](/writing/install-isaac-lab-in-5-minutes-with-pixi/) to create the simulation environment. The linked guide includes the project repository and platform-specific setup tasks.

### 3. Install LeRobot

Clone the [LeRobot repository](https://github.com/huggingface/lerobot) and follow its current installation instructions.

The project uses Isaac Sim and Isaac Lab for simulation and training, and LeRobot for robot-learning workflows. See the [project overview](/writing/so-arm100101-lerobot-isaac-sim/) for scope, prerequisites, milestones, and the remaining walkthroughs.
